# 🐍 Python с нуля — Интерактивная образовательная платформа

> Современный интерактивный веб-тренажёр для изучения Python с нуля прямо в браузере. Полностью статическое приложение без backend-сервера, готовое к бесплатному развёртыванию на **GitHub Pages**!

---

## ✨ Ключевые особенности платформы

### ⚡ 1. Исполнение Python в браузере (Pyodide + Web Worker)
- **Zero-Backend**: Код на Python 3.12 выполняется на 100% локально в браузере пользователя с помощью WebAssembly-компилятора **Pyodide v0.26.4**.
- **Защита от зависаний**: Pyodide запущен в отдельном фоновом потоке (**Web Worker**). Если ученик напишет бесконечный цикл `while True:`, интерфейс не зависнет, а встроенный тайм-аут (5 секунд) или кнопка **«Остановить»** мгновенно прекратят выполнение.
- **Интерактивный ввод `input()`**: Поддержка ввода пользовательских данных через красивую консольную панель с очередью ввода.
- **Виртуальная файловая система**: Поддержка операций с файлами (`open()`, `read()`, `write()`) через виртуальную файловую систему Emscripten.

### 🛡️ 2. Человечные ошибки на русском языке
Вместо пугающих англоязычных стектрейсов платформа анализирует ошибки Python и показывает понятные карточки:
- Извлечение точного номера строки и подчёркивание места сбоя.
- Понятное объяснение на русском языке для всех частых типов: `SyntaxError`, `IndentationError`, `NameError`, `TypeError`, `ZeroDivisionError`, `ValueError`, `IndexError`, `KeyError`, `TimeoutError`.
- Пошаговые советы по исправлению и возможность раскрыть оригинальный traceback.

### 📚 3. Полный практический курс: 8 модулей, 40 уроков
1. **Модуль 1: Знакомство с Python и первая программа** (5 уроков)
2. **Модуль 2: Переменные, типы данных и арифметика** (5 уроков)
3. **Модуль 3: Условия и логические выражения (if-elif-else)** (5 уроков)
4. **Модуль 4: Циклы (for, while, break, continue, вложенные)** (5 уроков)
5. **Модуль 5: Строки и списки (срезы, методы, индексация)** (5 уроков)
6. **Модуль 6: Функции (def, return, аргументы по умолчанию, scope)** (5 уроков)
7. **Модуль 7: Словари, множества, кортежи и файлы** (5 уроков)
8. **Модуль 8: Исключения, модули и итоговый мини-проект RPG** (5 уроков)

### 🎯 4. Пять интерактивных типов заданий
- `code` — написание программного решения в редакторе **CodeMirror 6** с проверкой на открытых и скрытых тестах.
- `find_error` — поиск и исправление намеренно допущенной ошибки в готовом коде.
- `predict_output` — тренировка понимания кода без запуска: анализ и ручной ввод ожидаемого вывода.
- `fill_blanks` — заполнение пропусков в кодовой строчке с мгновенной валидацией.
- `quiz` — интерактивные вопросы с вариантами ответов и подробным разбором каждого варианта.

### 💡 5. Трёхуровневая система подсказок и анти-чит
- **Уровень 1**: Направляющая подсказка (наводящий вопрос).
- **Уровень 2**: Детальный алгоритмический разбор.
- **Уровень 3**: Эталонный код решения (разблокируется только после 2–3 реальных попыток решения).

### 🏆 6. Геймификация и сохранение прогресса
- **Локальное сохранение**: Весь прогресс (решённые задачи, пройденные уроки, ответы на квизы) хранится в `localStorage`.
- **Серии дней (Daily Streak)**: Подсчёт ежедневной непрерывной активности.
- **Система ачивок**: 10 достижений за решение задач, прохождение квизов, исправление ошибок и модульные успехи.
- **Резервное копирование**: Экспорт и импорт прогресса в формате JSON, возможность полного сброса.

### 🔄 7. Синергия со Stepik
- Встроенный плеер шагов курса со Stepik прямо в уроке (iframe).
- Возможность развернуть плеер на весь экран или открыть урок на Stepik в новой вкладке.
- Готовый клиент OAuth2 Client Credentials для работы со Stepik API.

## 🚀 Быстрый старт локально

### Требования
- Установленный **Node.js** версии 18+ (рекомендуется LTS 20+)
- Менеджер пакетов **npm**

### Установка и запуск

```bash
# 1. Перейдите в каталог проекта
cd python-zero

# 2. Установите зависимости
npm install

# 3. Запустите сервер разработки
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000/`

### Сборка для production

```bash
npm run build
```
Готовая статическая сборка будет скомпилирована в каталог `dist/`.

## 🌐 Деплой на GitHub Pages

### Способ 1: Автоматический деплой через GitHub Actions (Рекомендуемый)

В репозитории уже настроен рабочий процесс `.github/workflows/deploy.yml`:
1. Запушьте код в репозиторий на GitHub (ветка `main` или `master`).
2. В настройках репозитория перейдите в **Settings** -> **Pages**.
3. В выпадающем списке **Build and deployment -> Source** выберите **GitHub Actions**.
4. При каждом коммите проект автоматически соберется и задеплоится на GitHub Pages!

### Способ 2: Ручной деплой с gh-pages

```bash
npm run build
npx gh-pages -d dist
```

### 1. Структура каталога `public/content/`:
```

├── manifest.json            # Оглавление всех 8 модулей и 40 уроков
├── module-1/                # Уроки 1-1 ... 1-5
├── module-2/                # Уроки 2-1 ... 2-5
...
└── module-8/                # Уроки 8-1 ... 8-5
```

## 🔑 Настройка интеграции со Stepik API (Опционально)

Для работы OAuth2 со Stepik API скопируйте файл `.env.example` в `.env` и укажите данные вашего приложения:

```bash
cp .env.example .env
```

В файле `.env`:
```env
VITE_STEPIK_CLIENT_ID="ваш_client_id"
VITE_STEPIK_CLIENT_SECRET="ваш_client_secret"
```
